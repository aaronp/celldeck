Stage

  • Pull apart. Drag an icon out of its bubble. Past the membrane it pinches off into its own bubble.
  • Merge. Drop an element or a whole bubble onto another bubble.
  • Add around. Select a bubble, then Add around. New bubbles bud off and the ring re-spaces itself evenly.
  • Tags & filter. Tag bubbles and elements in this panel. Type in the filter bar (/) or use the funnel to pick tags and icons; everything else fades back.
  • Connect. Turn on Connect (C), then drag from one element to another. Click a line to label and style it.
  • Views. Save view snapshots the stage. In Present, → morphs to the next one.
